# Muse tool review contract

Generated by `go run ./scripts/muse-tools`; do not edit generated files. Proposed review classifications require Meta approval.

Endpoint: `/mcp?hosted=1&profile=muse`. OAuth grants `tincan` or `tincan:read`. The read-only grant cannot execute any write, including through HTTP, refresh or browser sessions. Sensitive writes need Muse approval on every use; this document does not attest to observed host prompts.

All operations share HTTP ingress limits of 600 requests per client IP per minute and MCP limits of 600 per authenticated agent per minute. Operation-specific constraints appear in descriptions/inputs. Tool failures return `isError=true` with JSON error code/message in content; an HTTP 200 does not establish success. Common failures: insufficient_scope, unauthorized, forbidden, not_found, rate_limit, message/storage quota, room_archived, idempotency_conflict, stale revisions and encryption_runtime_required. Status handling below is part of the review contract.
